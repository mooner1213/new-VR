# 잔해 속의 숨 — 매몰 인트로 v2

## 영상의 성격
AI 생성 1인칭 콘셉트 이미지를 바탕으로 작은 시점 변화·노출 변화·분진 질감·붕괴/잔해/호흡 효과음을 합성한 영상 시안입니다. 실제 Unity 플레이 녹화나 물리 시뮬레이션 영상이 아닙니다. 신체나 파편이 독립적으로 움직이는 완전한 3D 애니메이션은 아닙니다.

## 수정한 방향
- 하체와 허리를 덮는 콘크리트로 이동 불가능한 상태를 표현합니다.
- 몸과 천장 사이가 극도로 좁은 생존 포켓입니다.
- 손에 든 스마트폰 LED 이외의 외부 광원을 배제한 구도를 목표로 합니다.
- 철근, 부서진 골재, 분진, 손과 의복의 먼지로 현장감을 강조합니다.
- 이동하는 카메라 대신 제한된 상체 움직임을 연상시키는 작은 시점 변화만 넣습니다.

## 실제 VR 구현 시
생성 이미지는 분위기 참고용입니다. 모델·충돌·리깅을 추출할 수 있는 게임 에셋이 아닙니다. 실제로는 아래 구성을 별도로 제작해야 합니다.

1. 플레이어 의상/하체 모델과 허리 위를 덮는 슬래브를 배치합니다. 손이 닿는 생존 포켓은 안전한 실제 움직임 범위를 확보하고 시각적으로 좁아 보이게 조정합니다.
2. 천장과 옆 벽을 깨진 콘크리트 메시로 구성하고 철근은 근접부에만 디테일을 집중합니다. 실제 돌출 충돌은 손·머리 추적을 방해하지 않게 구성합니다.
3. 휴대폰 Spot Light 하나, 베이크된 약한 간접광, 시야 안쪽의 적은 수의 분진 파티클을 사용합니다. Quest의 실시간 볼류메트릭 안개는 별도 성능 검증이 필요합니다.
4. 하체는 고정하되 HMD의 머리 추적을 유지합니다. 영상용 카메라 흔들림을 VR 카메라에 그대로 적용하지 않습니다. 여진은 천장·철근·입자·사운드를 움직여 표현합니다.
5. 스마트폰과 천에 XR Grab Interactable을 적용하고, 휴대폰 화면에 World Space UI를 둡니다. 이 상호작용은 본 영상에는 구현되어 있지 않습니다.
6. 압박감과 시야 제한은 접근성 옵션과 즉시 종료 기능으로 조절 가능하게 합니다.
